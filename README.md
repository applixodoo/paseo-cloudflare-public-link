# Cloudflare Public Link for Paseo

A [Paseo](https://paseo.sh) plugin that turns a service running in a workspace, such as a dev server or preview, into a temporary public HTTPS link on `trycloudflare.com`. Share it with a customer, a colleague, or your phone, with optional email PIN protection and no Cloudflare account.

See [OVERVIEW.md](OVERVIEW.md) for what it does, setup, and limits.

Development: `npm install`, `npm run typecheck`, `npm test`.

# Cloudflare Public Link for Paseo

A [Paseo](https://paseo.sh) plugin that shares a running workspace service through a temporary Cloudflare Quick Tunnel (`trycloudflare.com`), protected by an email one-time PIN by default.

See [OVERVIEW.md](OVERVIEW.md) for what it does, setup, and limits.

Development: `npm install`, `npm run typecheck`, `npm test`.
